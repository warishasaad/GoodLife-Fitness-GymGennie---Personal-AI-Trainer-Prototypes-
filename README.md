# 🏋️ GymGenie — Your AI Personal Trainer

GymGenie is an AI-powered fitness app that personalizes your workout and nutrition journey using cutting-edge artificial intelligence.

---

## ✨ Features

### 🤖 AI Fitness Assessment
Captures the user's goals, experience, and preferences to personalize their journey.

### 💪 Adaptive Workouts
Workout plans that adjust automatically based on the user's performance and feedback.

### 👁️ Form Analysis
Provides real-time feedback on the user's exercise form to improve safety and results.

### 🍽️ Meal Logging
Allows users to log meals via photos or barcodes, offering personalized nutrition insights.

### 💬 24/7 AI Coach Chat
An always-available AI assistant for guidance, motivation, and real-time support.
